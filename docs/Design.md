# 言灵 Design

**产品：** 言灵（kotodama） v1.0.3  
**对应需求：** [PRD](./PRD.md) · [TRD](./TRD.md)  
**画布规范：** [Ant Design v6 默认主题](./ant-design/design.md)  
**参考界面：** [A2UI Studio](./a2ui-studio/)（进门、图鉴）· [A2UI Composer](./composer/)（**工坊首页三栏**、分组、设置页）  
**验收用例：** [TEST](./TEST.md)

相对 v1.0.2：文案、路由、三套表面、落地页空桌都不改。这一版只改**开始创建进入工坊之后的首页骨架**——按 Composer 的三栏：说话 | 预览 | 源文件。现在的杂乱来自底栏 JSON 横压整张书桌，纸页被挤成一条缝。v1.0.3 让预览占满中间列；JSON 立在右侧；数据 / 事件 / 错误贴在预览列底，像 Composer 中间栏下半。三栏**不要等宽**：预览最宽。左轨仍是文字，不要收成 Composer 图标轨。不要 Gemini 空状态广告，不要 Raw Messages。

学参考产品的气，不学它们的皮。Studio 进门是大输入、图鉴一点一组件；Composer 工坊是三栏职责、图鉴分组、设置单独成页、chrome 安静。不要学 Studio 的红选中、行业胶囊、黑顶栏；不要学 Composer 的图标轨、诊断双卡、三栏等宽、连接徽章。

这份文档决定工作室和工坊长什么样、字怎么写、主次怎么分。实现时改 chrome，不要改生成页的 Ant Design 语义。

---

## Subject

言灵：把说出来的话收成一页稳定的界面。

- **谁用：** 先说话的人；需要时先翻目录和例子的人；必要时才打开树、属性和 JSON 的人。
- **这一产品的唯一工作：** 让人看见「我说了 → 这一页定了」。
- **材料：** 话、纸页、印。不是聊天机器人皮肤，也不是 IDE 皮肤，也不是卡片商城。

预览里的页面必须是 Ant Design 的页面：Natural、Certain、Meaningful、Growing。工作室和工坊是托住这张纸的屋子和书桌。屋子可以有自己的印记；纸页上不能出现工坊的装饰。

落地页不能抢过纸页。进门再素，生成页也必须更像「真正的那一页」。

---

## Three surfaces

v1.0.3 仍用三套职责，不要混成一套。工作室和工坊共用言灵种子；纸页永远是 Ant Design 默认。

| Surface | Job | Theme |
| --- | --- | --- |
| **工作室** | 左轨、落地页、图鉴、案例、设置 | 言灵种子，见下方 tokens |
| **工坊** | 顶栏动作、说话列、属性抽屉、源文件列 | 同一套言灵种子 |
| **纸页** | 工坊预览、图鉴预览、案例预览里渲染出的界面 | Ant Design 默认 `defaultAlgorithm` / `darkAlgorithm`，不改 `colorPrimary` |

实现：外层 `ConfigProvider`（已有 `XProvider`）负责工作室和工坊。每一个预览根节点再包一层 `ConfigProvider`，只传 Ant Design 默认算法和默认 seed，把工坊的 `colorPrimary` 隔开。图鉴和案例的预览走同一层，不要第三套主题。

这样生成页在任何时候都长得像普通 Ant Design 后台，而不是「言灵皮肤的页面」。稳定来自目录和协议，观感来自 Ant Design 默认主题。

## Token plan

### Why this, not a template

不用暖奶油底 + 衬线标题 + 陶土强调（常见 AI 落地页）。不用近黑底 + 霓虹强调（常见 AI 控制台）。不用报纸细线通栏（常见「编辑感」模板）。不用青绿主色 + 大 Hero（常见 SaaS 营销页）。也不要用三栏 IDE 默认皮：等权按钮、大卡片提示、灰画布上漂一块白卡片。

也不抄参考产品的皮：

| 参考 | 可学 | 不要学 |
| --- | --- | --- |
| A2UI Studio 落地页 | 进门是大输入；提示和空状态同一组任务 | 红品牌当选中色；漂浮聊天卡片；行业提示胶囊；传图识别 |
| A2UI Studio 图鉴 | 一点一个组件：预览 → JSON → 属性 | 把 18 个组件塞进左轨，让四个入口跟着跳；移动端 / PC 切换 |
| A2UI Studio 卡片市场 | — | 密铺卡片商城。言灵只有三个案例 |
| A2UI Composer 图鉴 | 布局 / 内容 / 输入三组；预览 + JSON + 属性表 | 只放图标的窄轨 |
| A2UI Composer 工坊 | 三栏职责：说话 | 预览（主列） | 源文件；逃生舱叫数据 / 事件 / 错误，贴在预览列底 | 三栏等宽；图标轨；Gemini 空状态广告；Raw Messages；「Rendered A2UI Preview」大标题框 |
| A2UI Composer 设置 | 通道配在单独一页；Key 只存本地 | 渲染器切换、连接诊断、多 Key 槽 |

言灵的材料仍是墨、纸、印。工作室是一间**屋子**：左边是目录牌，中间是书桌。落地页是还没放下纸的空桌。唯一的色风险仍是字标旁的印泥，不用作按钮色，也不用作左轨选中色。

v1.0.3 的克制：瑞士式留白 + Composer 三栏骨架。不是杂志大字，不是电子墨水纹理，不是紫粉 AI 皮，不是等权 IDE。chrome 少阴影、少嵌套、少分割线。工坊首页的气势来自**中间那一列铺满的预览**，不来自底栏里摊开的 JSON。

### Color

工坊和外壳只改最小种子，其余交给 Ant Design 算法推导。

| Token | Light | Dark | Role |
| --- | --- | --- | --- |
| `ink` | `#1F1F1F` | `rgba(255,255,255,0.88)` | 主文字。等同 Ant Design `on-surface` |
| `mist` | `#595959` | `rgba(255,255,255,0.65)` | 次要文字 |
| `paper` | `#E6EAEF` | `#121212` | 书桌。比 Ant Design `#F5F5F5` 更深更冷，让白纸页坐上去 |
| `sheet` | `#FFFFFF` | `#1F1F1F` | 纸页表面、左轨、顶栏。预览内层用 Ant Design `colorBgContainer` |
| `rule` | `#D9D9D9` | `#424242` | 分割。用 token，不写死 hex |
| `seal` | `#CF1322` | `#FF4D4F` | **仅**字标旁竖章。Ant Design `red-7` / `error`，不作 primary，不作轨选中 |

`colorPrimary` 保持 `#1677FF`。对话发送、焦点环、选中描边、左轨选中都走它。不要把印泥红做成主按钮或导航色。

纸页内层：不覆盖 `colorPrimary`、状态色、圆角、字号。完整数值以 [Ant Design design.md](./ant-design/design.md) 为准。

### Type

Ant Design 界面只用 400 和 600，14px 正文。工作室控件遵守这条。不要给 chrome 套展示字体（包括京黑、朗正体一类标题体）——字标以外全部走系统栈。

| Role | Face | Use |
| --- | --- | --- |
| Display | `"Noto Serif SC", "Source Han Serif SC", "Songti SC", serif` | **只用于**顶栏两个字「言灵」。字重 600，字号 18px |
| Room | Ant Design 系统栈 | 落地页、图鉴、案例、设置的 `<h1>`：24px / 600 / 32px，`text-wrap: balance` |
| Body | Ant Design 系统栈（`-apple-system`, `Segoe UI`, `PingFang SC`, …） | 轨、对话、按钮、属性、欢迎、图鉴说明。14px / 400 |
| Section | 系统栈 | JSON、属性：14px / 600。是 `<h2>`，不是第三张卡片的标题 |
| Code | `"SFMono-Regular", Consolas, Menlo, monospace` | 源文件列和图鉴 / 案例里的 JSON。13px / 20px |

不要给标题、Tab、按钮、左轨、落地页大标题套衬线。衬线一旦离开字标，屋子会变成模板杂志。v1.0.1 把房间标题压成 16px，屋子看起来像表单；v1.0.2 用 24px 把房间撑开，仍远小于杂志 Hero。

### Layout

4px 网格。间距只用 Ant Design 的 xs/sm/md/lg/xl（4 / 8 / 16 / 24 / 32 / 48）。顶栏高度 48px。整屏用 `100dvh`，并加 `env(safe-area-inset-*)`。最小可用宽度 1024px。v1.0.3 仍不做左轨收起。

结构是屋子里的书桌，不是第二套 IDE。左轨永远在。工坊首页按 Composer：**说话 | 预览 | 源文件**，预览是唯一主列。图鉴、案例、设置仍是同一张桌上的另几份东西，不要做成商城或文档站。

**纸的特权：** 图鉴预览、案例缩略 / 详情预览仍是纸（两层落影 + 1px `rule` + 圆角 4px）。工坊首页不再把生成页做成灰桌上漂的一张卡——中间列本身就是 `sheet`，生成页铺满这一列（内边距 32×24）。顶栏、左轨、说话列、源文件列、提示列表**不是纸**，不要再套一层卡片或第二道阴影。JSON 横在预览底下，是 v1.0.2 工坊杂乱的来源。

```
┌─ 屋子 ──────────────────────────────────────────────────┐
│ 印 言灵     〔工坊才出现：打开 下载 │ 撤销 重做 新建〕 深色 │
├──────┬──────────────────────────────────────────────────┤
│ 左轨 │  开始创建 → 落地页 或 工坊                         │
│ 168  │  基础组件 → 图鉴                                   │
│      │  精选案例 → 三张纸 / 一页详情                      │
│ 文字 │  设置     → 三项通道                               │
│ 不是 │                                                  │
│ 图标 │                                                  │
└──────┴──────────────────────────────────────────────────┘
```

工坊在屋子里的样子（左轨不消失；首页骨架对齐 Composer）：

```
┌─ 屋子 ──────────────────────────────────────────────────────────┐
│ 印 言灵          打开 下载 │ 撤销 重做 新建 │ 深色               │
├──────┬──────────┬──────────────────────────┬───────────────────┤
│ 左轨 │ 说话     │  预览（主列，sheet）       │  源文件 JSON      │
│ 168  │ 280px    │  生成页铺满这一列          │  320px 默认打开  │
│ 开始 │ 可拖     │  选中：列内右侧抽屉「属性」 │  可拖 280–400    │
│ 创建 │ 输入贴底 │                            │  可收到 40px     │
│      │          ├──────────────────────────┤                   │
│      │          │  数据 · 事件 · 错误  40px │                   │
└──────┴──────────┴──────────────────────────┴───────────────────┘
```

不要再把 JSON / 数据 / 事件 / 错误做成横贯三栏的底栏。那会把预览压成一条缝。

区域职责：

| 区 | 宽度 / 高度 | 默认 | 角色 |
| --- | --- | --- | --- |
| 左轨 | 168px，不可拖 | 打开 | `sheet`，右边 1px `rule`。四个入口，文字优先 |
| 说话 | 280px，可拖 240–320 | 工坊打开 | `sheet`，右边 1px `rule`。Tab **说话** 默认 |
| 预览 | `minmax(0, 1fr)` | 打开 | 唯一 `<main id="sheet">`。`sheet` 底，生成页铺满，不要灰底漂卡 |
| 源文件 | 320px，可拖 280–400；收 40px | **打开** | 只放 **JSON**。`sheet`，左边 1px `rule`。这是 Composer 右栏 |
| 记录 | 预览列底，收 40px / 开 160px（可拖 160–280） | **收起** | **数据** · **事件** · **错误**。不要 Raw Messages |
| 属性 | 抽屉 280px，无遮罩 | **关上** | 挂在预览列里，不要盖住源文件列 |

工坊预览：不再用最大宽度 840px 的落影纸。中间列有多宽，生成页就有多宽；内边距 32×24。空预览：`Empty`，**没有可预览的页面**。图鉴和案例的预览仍用纸的规格（落影、最大 840px、可更矮到 200px）。

分栏拖拽条做成 1px `rule`，不要宽槽。

z-index 只用五档：`skip` 50 · `header` 20 · `rail` 20 · `drawer` 30 · `source` 20。确认框走 Ant Design Modal 默认层，不要手写 9999。

持久化只记说话列宽、源文件列宽、源文件是否展开、记录条是否展开、记录条高度。不要把左轨宽度、落地页滚动位置写进草稿。旧键 `dockOpen` / `dockSize` 读到时丢弃，改用上面五项的默认值。

### Signature

记住这一产品的，应是 **说话之后，中间列里定下一页**，加上顶栏左侧的印与「言灵」。

v1.0.3 的那一笔：工坊首页中间列铺满，不再被底栏 JSON 切成上下两截。落地页**还没有纸**——标题、输入、三行提示直接坐在书桌上。人说完一句，才进工坊三栏、才在中间列落下页面。不要把进门做成一张更大、更圆、阴影更重的聊天卡片。设置不要再做成登录页那样的居中白卡片。案例列表的缩略图就是那张纸，不要外套一张卡片。

生成成功时，纸页只做一次 200ms 落下：`translateY(8px) → 0`，`opacity 0.7 → 1`。尊重 `prefers-reduced-motion`：关掉位移，只换内容。落地页切到工坊不要翻页动画。

不要机器人头像、不要大提示卡片、不要给印做呼吸、不要 01 / 02 编号、不要行业胶囊。

## Ant Design values in this product

| Value | 言灵里怎么落地 |
| --- | --- |
| Natural | 控件用 Ant Design 默认形态。发送、输入、Menu、Tab、树、表单都不自造。左轨用 `Menu`，不要自绘导航。 |
| Certain | 校验失败时旧纸页不动。左轨四个入口永远在，选中态明确。人始终知道自己在落地页、工坊、图鉴、案例还是设置。 |
| Meaningful | 每一屏只有一个 primary。落地页是发送，案例详情是「用这一页」，设置是「保存」，工坊是说话栏发送。顶栏没有 primary。 |
| Growing | 同一套纸页既能画登录表单也能画列表。外壳加页时只加房间，不换皮肤、不扩目录。 |

Ant Design 的 Do/Don't 全部适用于纸页。工坊和外壳额外遵守：印泥红不是 primary；不要给相邻控件混用 16px 圆角。

## Studio chrome

键盘用户第一个焦点是跳过链。落地页：**跳到输入**（`#prompt`）。工坊：**跳到纸页**（`#sheet`）。图鉴 / 案例详情：**跳到预览**（`#sheet`）。设置：**跳到表单**（`#channel-form`）。未聚焦时视觉隐藏。不要把它做成第三个主按钮。

### Header

顶栏与左轨同色（`sheet` / `colorBgContainer`），底边 1px `rule`。不要用主色顶栏。整间屋子共用这一条。

左：印在字前。印是 5×18 圆角 1px 的竖章，`seal` 色，`aria-hidden`。字标「言灵」链到「开始创建」，18px / 600 / 衬线 / 字距 0.16em，`translate="no"`。不要写成 Logo 图。

字标**不再是** `<h1>`。每一页自己的标题才是这一页唯一的 `<h1>`。字标是文字链接，`aria-label="言灵，返回开始创建"`。

右：深色 `Switch` 始终在。短标签在左。`aria-label="深色"`。

工坊动作只在工坊可见时出现，仍是 `Button type="text" size="small"`，不要描边按钮。两组之间、以及与深色之间，用 `Divider` 竖线：

1. **打开**、**下载**
2. **撤销**、**重做**、**新建**
3. **深色**

落地页、图鉴、案例、设置**没有**打开 / 下载 / 撤销 / 重做 / 新建。那些是书桌动作，不是屋子动作。

「新建」二次确认不变：**新建这一页？当前页会清掉。说话也会从头开始。** 确认「新建」，取消「留下」。新建后留在工坊，不要退回落地页。

隐藏 file input：`aria-label="打开 JSON"`。

### Rail（左轨）

`Menu` 直排，宽度 168px。四项都要有可见文字，不要做成 Composer 那种只剩图标的窄轨。

| key | 文案 | 图标（Ant Design outlined，16px） |
| --- | --- | --- |
| `create` | 开始创建 | `EditOutlined` |
| `catalog` | 基础组件 | `AppstoreOutlined` |
| `examples` | 精选案例 | `FileTextOutlined` |
| `settings` | 设置 | `SettingOutlined` |

图标只辅助文字，不替代文字。不要 emoji。

选中：Ant Design Menu 默认选中（浅底 `#E6F4FF` + 主色文字）。不要用印泥红或粉色底。不要 2px 左竖条另做一套。

工坊打开时，「开始创建」保持选中。

左轨是 `nav`，`aria-label="工作室"`。当前项 `aria-current="page"`。四项用真正的链接（可 Cmd/Ctrl 点开），不要只靠 `onClick` 跳转。

四个入口要对得上可停留的地址，刷新不丢当前房间。图鉴的当前组件、案例的详情也要进地址。具体路由写法见 TRD；这里只要求人能从地址看出自己在哪。

左轨与顶栏之间留 8px，项与项之间留 4px。不要让第一项贴着顶栏底边。

### 开始创建：落地页

落地页是空桌，不是聊天皮肤，不是营销 Hero。

书桌铺 `paper`。内容垂直居中，最大宽度 560px，左右不贴边。

```
              从这里说出一页          ← h1，24px / 600 / 32px，系统栈
     说完后进工坊。中间会换成一页，
           可以留下、再打开。          ← 14px / 400，mist

     ┌─────────────────────────────────┐
     │ 描述你想要的界面…          发送 │  ← 同一套 Sender，1px rule，无落影
     └─────────────────────────────────┘

                   可以说
            做一个登录表单             ← 一行一条，不要胶囊，不要行下划线
            做一个设置页
            做一个带筛选的列表
```

规则：

- 输入复用工坊的 `Sender`。placeholder 相同：**描述你想要的界面…**。发送是这一屏唯一的 primary。Sender 是书桌上一道发丝框（`sheet` 底 + 1px `rule` + 圆角 4px），**没有**落影，不要做成漂浮聊天卡片。
- 三个提示与工坊空状态同一组文案。仍用 `Prompts`，压成列表：字，不是行下划线清单。悬停变主色。不要胶囊、不要多行业。
- 标题到说明 8px，说明到输入 32px，输入到「可以说」32px。
- 提交（回车、发送、点提示）后进入工坊，并把这句话放进说话栏 **自动发送**。不要先停在工坊空输入里等人再点一次。
- 通道没配齐时，落地页仍可提交并进工坊；发送失败走工坊说话栏的通道提示，不要在落地页另做诊断卡。
- **不做：** 传图识别、输入框底下的工具条、漂浮白卡片、大阴影、装饰插画、比纸页更重的圆角。

导航：

- 已在工坊时，再点「开始创建」留在工坊。
- 从基础组件 / 精选案例 / 设置回到「开始创建」：若已经进过工坊（发送过，或用过「用这一页」），打开工坊；否则打开落地页。
- 刷新时若已有当前稿，直接进工坊，不要把稿藏到落地页后面。

## Chrome specs（工坊）

工坊嵌在左轨右侧。v1.0.3 首页骨架对齐 Composer 三栏，不要再做成「左说话 + 中漂纸 + 底 JSON」。

### Speech column（说话）

`sheet` 底。Tab：**说话** | **组件**。激活态：主色文字 + 2px 下划线，无填充。内容**顶对齐**，不要在空栏里垂直居中。

空状态：

- 标题 `<h2>`：**说你想要的那一页**（16px / 600）
- 说明：**说完后，中间会换成一页。这一页可以留下、再打开。**

组件 Tab：`Tree` / `Button` `size="small"`。插入区不要彩色积木。

## Flows

### 进门

1. 打开产品。无当前稿：落地页。有当前稿：工坊。
2. 在落地页说一句或点提示。
3. 进入工坊，这句话自动发送。说话栏出现「正在写下这一页…」。纸页若仍空，保持 Empty，不闪半份 JSON。
4. 通过校验：气泡换成一句确认；纸页换新内容并做一次落下。
5. 未通过：气泡换成失败句；纸页完全不动（空则仍 Empty）。

### 说成一页 / 再改一版

与 v1.0.0 相同，发生在工坊内。同一说话线程。不要新开「会话卡片」。顶栏「新建」才清空说话。

### 试

在纸页里填、点。结构不变。案例详情的预览同样可试。要改布局，回到说话，或打开逃生舱。图鉴预览不要求试填。

### 看目录

点「基础组件」→ 选一个名字 → 看预览、JSON、属性。复制 JSON 不会改当前稿。

### 用例子

点「精选案例」→ 点一张纸 → 看预览和 JSON → **用这一页** → 需要时确认「换上」→ 进工坊。

### 配通道

点「设置」→ 填三项 → **保存**。下一句对话用新通道。清空三项并保存，则退回环境变量。

### 带走

**下载** 当前已通过校验的纸页源文件。成功无 toast 也可以；若做反馈，用 `message.success`：**已下载 kotodama.json。** 下载文件里不能出现 API Key。

**打开** 失败：纸页不动，`Alert` 或「错误」Tab 指出原因。不要用浏览器原生 `alert()`。

## Accessibility

- 焦点环用 Ant Design 默认，不要 `outline: none`。可聚焦控件用 `:focus-visible`，不要在点击时画环。
- 印装饰 `aria-hidden`。字标仍是可读文本「言灵」，但是链接不是 `<h1>`。字标链接要有 hover 与 `:focus-visible`。
- 每一房间一个 `<h1>`：落地页「从这里说出一页」；工坊视隐「工坊」；图鉴为组件名；案例列表「精选案例」；案例详情为案例标题；设置「设置」。JSON / 属性是 `<h2>`。
- 第一个可聚焦控件是跳过链，目标随房间变。未聚焦时视觉隐藏；聚焦用 `:focus-visible` 滑入。
- 左轨文字可见；图标 `aria-hidden`。不要做成无障碍名称为空的图标按钮。
- 「正在写下这一页…」对 `aria-live="polite"` 可见。失败句同样进入 live region。
- 纸页选中不能只靠颜色：已有 2px 描边，保留。
- 设置三项必须有 `<label>`（`htmlFor` 对上控件 `id`）。Key 用密码框，并提供显隐。保存后的回看仍是掩码。非登录字段 `autocomplete="off"`，URL / Key `spellCheck={false}`。
- `prefers-reduced-motion: reduce` 时关掉纸页位移。过渡只写 `transform` / `opacity` / `color` / `border-color`，不要 `transition: all`。
- 工坊深色用 `darkAlgorithm`，纸页内层同步算法、仍用默认 seed。外壳跟工坊同一算法。不要手工反色。根节点设 `color-scheme`，让滚动条和系统控件跟主题走。
- 工坊根：`touch-action: manipulation`。说话列、属性抽屉、源文件列、记录条、图鉴 JSON 井：`overscroll-behavior: contain`。
- 主色与白字对比：Ant Design 已说明 `#1677FF` 上白字可能低于 WCAG AA。v1.0.3 不改 primary；严格无障碍时再通过 `ConfigProvider` 加深 `colorPrimary`，工作室、工坊和纸页一起加深，避免两套主色。
- 触控目标：左轨每一项高度至少 40px（Ant Design Menu 默认够用）。不要把可点区域收成只有 16px 图标。
- 长标题、案例一句：`min-width: 0` + `truncate` / `line-clamp`，不要撑破横排。

| 源文件列默认收起 | Composer 首页右栏是打开的；人要能对照协议 |
| 说话栏用机器人头像或 Gemini 广告 | 会变成聊天皮肤 |
| 案例页做成卡片商城 | 只有三个例子，密铺是假丰富 |
| 设置页做连接诊断 | 通道失败时说话栏能看出来即可 |
| Raw Messages | 不是主路径 |

---

## Do not

- 不要让生成页长出言灵衬线标题或印泥按钮。
- 不要两个 primary 并排（顶栏、落地页、设置页尤其不要）。
- 不要把 JSON 当作对话内容的一部分来「增强专业感」。图鉴和案例可以展示 JSON，因为那两页的工作就是看协议。
- 不要为工作室发明 Ant Design 预设盘以外的装饰色。印泥只用 `#CF1322` / `#FF4D4F`，且只用于字标旁竖章。
- 不要用 Studio 的红选中、胶囊提示、传图识别、卡片市场、黑顶栏。
- 不要用 Composer 的图标轨、渲染器切换、Gemini 空状态、连接徽章、诊断双卡、三栏等宽、Raw Messages。
- 不要用紫粉 AI 皮、电子墨水噪点、杂志超大字、报纸细线通栏。
- 不要用魔法数字间距。现有 `.editor-header` 的 48px 和 16px 已在网格上，保留。左轨 168px、说话 280px、源文件 320px、索引 200px 是网格值。
- 不要 `transition: all`，不要无替代的 `outline: none`。

实现入口：`EditorShell` 三栏 Splitter（说话 | 预览+记录 | 源文件）、工坊预览铺满中间列、`BottomDock` 拆成源文件列与记录条、`storage` 的 chrome 五项。落地页 / 图鉴 / 案例 / 设置仍按 v1.0.2 的空桌与少一层皮。纸页内部组件继续走 `@kotodama/antd-catalog`。
